# 研究更新记录

按 `YYYY-MM-DD-topic.md` 创建文件，例如主题可以是 `initial-review`、`earnings` 或 `thesis-change`。日期使用用户时区；同一天有多个主题时分别保存。模板目录不预先创建真实日期的更新。

每份更新至少包括：

1. 更新日期、事件日期或报告期、当时掌握的材料范围。
2. 更新前的判断或估值假设，引用原记录。
3. 新事实与证据编号；推断、假设和未知项另列。
4. 与原判断一致或冲突的地方，包含最强反对解释。
5. 更新后的判断、哪些参数改变、哪些不变及原因；资料不足可以暂不改变结论。
6. 下一步、复查条件，以及实际修改的文件。

将更新链接加入 [thesis.md](../thesis.md) 的判断历史，必要时修改 [valuation.md](../valuation.md)。保留原更新；纠错以追加说明或新更新记录解释，不能删除过去的错误判断。
