# 计算工具

这里预留给真正需要复算的 IRR、估值或数据处理脚本。现在没有足够的公司数据或现金流输入，因此不预先搭建计算库。

简单计算先在公司 `valuation.md` 写出公式与代入值；当多个情景或真实现金流时点使手算难以可靠复核时，再增加一个用途明确的 Python 脚本。

新增脚本优先使用 Python 标准库，记录输入、币种、单位、日期、公式与适用条件；输出不得自动改写持仓。涉及 IRR 时检查无解、多解和收敛问题，不能把错误返回为看似有效的数字。先用已知结果和边界案例验证，再应用到实际研究。

当前无需安装第三方库，也无需启动服务。已有的文件检查工具在 [evals/](../evals/README.md)。
