# 行业分析

> 状态：助手提供的通用问题与口径参考，尚非用户确认的投资方法。使用前读取[长篇框架](long-form-investment-framework.md)与[投资 ontology](../investment-ontology.md)；其中的措辞不能替代用户对概念的具体解释。发现差异时记录张力，不擅自选择默认方法。

研究需求从哪里来、产业链谁获得利润，以及这些利润是否可持续。

- 客户、供应商和分销渠道各有多大议价权？收入增长由量、价还是产品结构驱动？
- 行业供需、产能、资本投入和库存处于什么阶段？周期性利润能否代表正常盈利？
- 竞争者如何进入、退出或替代当前产品？监管、技术和商业模式会怎样改变利润池？
- 市场规模数据的定义、地域、期间及来源是什么？不要把市场增长直接当成公司增长。

**最小产出**：行业如何赚钱、主要变化、公司所处位置、一个最强反对观点、待核实的问题；重要结论附证据编号。
