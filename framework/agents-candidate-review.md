## 详细内容为什么没有复制进候选稿

| 内容 | 留在哪里 | 不复制的理由与仍须遵守的部分 |
| --- | --- | --- |
| 20%/特定15%、尾部通常≤1%、核心约10家、滚动窗口/本币 | [估值](valuation-risk.md)、[机会选择](opportunity-selection.md) | 有适用情境、不是所有研究同一门槛。候选17要求查原条件，不能等于全部取消；三年窗口非最长持有期 |
| 成熟企业均值样本、情景驱动、EPV及reverse IRR具体做法 | 估值框架，之后落实valuation Skill | 具体对象不同；候选保留谨慎修复、情景IRR加权、成长/option与价格隐含检查，不造统一公式 |
| Timee佣金/TAM、历史模型及不给其他新业务额外正值的当前判断 | [CASE002](../casebook/CASE002-timee-research-process.md)、[M011审阅](../casebook/CASE002-M011-review/README.md)、原材料 | 公司判断不能普遍化。研究Timee仍须读取当前直接M010等，不因候选未点名就退回旧GPT的普通8%加值 |
| 携程旅游场景的完整条件链、海外论文线索 | [生意质量B006](business-quality.md)、M012 | 属有条件机制例子；国内single-homing/论文适用未核实。候选4/10保留经济实质和前提验证，不把案例当结论 |
| 咖啡店半年、腾讯1–2/3年与业务阶段 | [管理层B012](management-capital-allocation.md)、M012 | 是进入常态/探索/考察盈亏例子，非回本承诺或统一关停年限；候选6保留阶段与关停纪律 |
| 语录、投资人观点及用户解释 | 原材料及对应长篇论述 | 保留认同/不认同、解释与不适用情形；候选不靠名人权威替代推理 |
| 具体访谈题目、指标口径、材料提取和版本操作 | casebook、材料索引、[工作区约定](workspace-conventions.md) | 不属于每次投资判断的核心原则；按路由查证，不能将未读当已读或提问当答案 |
| 尚未确认的Timee候选方法与通用Skill默认项 | M011案例审阅、Skills草稿 | 不因框架核对齐就自动成为用户规则；候选路由明确模板不能覆盖已明确方法 |

“详细内容移出”不是删除理念。路由要求读取对应文档；若今后某条约束频繁因未读取而失效，应按实际决策偏差调整路由或保留方式，不以字数为目标。

## 压缩行为检查

以下是本轮人工比较的假想情景，不是运行过的自动评测。检查候选能否维持长篇框架的判断方向：

| 情景 | 候选应保持的行为 | 对应条目 |
| --- | --- | --- |
| 优势已验证，增长支出压低当前利润/现金流 | 研究未来合理盈利、辨认再投入，不直接排除或无条件加回 | 1/4/6 |
| 一次性酒店预订但可能锁住长期旅游场景 | 研究忠诚与维护成本的条件链，不能只看订阅标签 | 4/10 |
| 高持股且有实锤欺骗；之后治理人物实质改变 | 当前红线不能持股抵消；改变后可翻篇/中性但须重研改善 | 5 |
| 立项通过后研究越深越不可估 | 扎实Too Hard是完成结果，可停止，不因沉没时间推进到买入 | 9/12 |
| 普通价值机会有明确优势/回报，但跑道短 | 可合理投资，不降基础门槛；相近风险收益时研究优先长期好机会 | 2/3 |
| 用海外OTA或同行利润率直接推国内公司结果 | 检验适用前提、本地证据与维护费用，不直接搬结果 | 4/6/10 |
| 知道董事会选举日，但治理兑现时间/成功率无依据 | 节点不等于终局；保留观察/Too Hard，不设50%造expected IRR | 9/11 |
| 模型提出各情景IRR加权 | 不能改成概率加权现金流后求IRR，合理倍数仍须谨慎 | 11 |
| 核心thesis变化或增长提前兑现 | 评估未来FCF及可估计性，不默认旧建议或按条数卖出 | 13 |
| 符合某IRR参考，但组合现金已少 | 现金与当前整体组合继续比较，不自动买入/投满 | 14/17 |
| 小概率归零且expected IRR高 | 先理解分布/具体事件/时间；小仓位仅控制组合影响，主仓仍看永久损失 | 9/15 |
| 新业务只是option或依赖想象协同 | 不自动给growth value，计真实成本；可信核心成长另评 | 7 |

人工比较未发现需要删去已对齐条件才能成立的规则；它不能证明所有未来研究行为一致，也不是投资表现验证。关键残余依赖是：具体研究必须沿路由读取详细条件，不能只凭候选稿的17条完成全部公司研究。

## 采用与后续工作分开

候选覆盖六类内容：核心目标、决策原则、认识/证据、thesis、组合/机会成本、简短路由。文件操作留工作区约定；公司事实、个人真实持仓及未证实案例没有填入。

先完成M014架构及行为预期核对，再检查候选是否保留正确理念和本轮人机边界；未经后续确认不替换临时AGENTS。不会顺带推送GitHub、重写全部Skills或开始新公司估值。前轮生成候选时没有修改其他文件，本轮只更新其状态/审阅路径并保留原17条来源分析。
