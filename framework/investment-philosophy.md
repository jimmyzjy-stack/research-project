## 已表达与尚未定义的边界

| 项目 | 当前状态 |
| --- | --- |
| 终身目标与研究重点 | 实际可投资远多于20家公司；合理普通value／事件／特殊机会也可配置，风险收益相近时研究优先潜在长期优秀企业，短期错价不主导体系 |
| 认知复利 | 持续研究优秀行业、跨国同行优秀公司及类似事件范式，积累可复用知识；不以最低换手率或只买compounder为目标 |
| 长期研究与季度资料 | 客户项目beat/miss预测不是当前长期Harness目标；保留季度经营证据检验thesis、现金流与资本回报，不从旧模板继承全部任务 |
| 投资期限 | 关注长期；当前滚动窗口如更新2026年至少预测2029并估值，非固定持有期；窗口可随研究讨论调整 |
| 研究市场与能力圈 | 命脉级可理解可预测，认识边缘并可延展或跨行业扩展；未给投资市场完整边界 |
| 回报要求与比较基准 | 理解前置，不以高模型IRR补偿；各情景IRR加权须有驱动／事件／概率／时间依据。20%／特定条件15%以上等按语境保留，不作自动交易线 |
| 组合风险边界与集中度 | 核心重点约10个好公司；符合条件的尾部小仓位往往不高于1%，持有跟踪即A。ABCD按研究资源内容深度划分，非质量排名 |
| EPV与增长计价 | 可信增长与option条件继续适用；EPV折扣在各情景中考虑，与IRR为关联判断，不另加统一硬折价 |
| Timee当前业务估值 | 用户判断核心零工护城河强、TAM较旧项目更谨慎，新行业仍有成长；FM/请负及长期/全职招聘不另加正估值，仍考虑成本和毁损，未给新TAM数字 |
| 下行标准 | bear并看极端事件；主要持仓不希望极端情况下显著永久损失，M012修正旧0 IRR表述，不是保证零损失 |
| 治理与理解下限 | 实锤红线不被持股抵消；懂至少能说清护城河差异、thesis／跟踪及反面信息论证；不是量表或充分保证 |
| 治理变化后重新研究 | 关键雷点/风险人物实质更换可翻篇、回风险中性；仍查改善、监控纠正，公开/一线资料均可提供证据；其他风险/警惕合并 |
| Thesis变化与持仓重审 | 不默认维持原建议；看未来FCF影响及可估计性，可估计变化连接IRR，不可估计则Too Hard，不能简单外推制造可计算性 |
| 现金选择 | 始终比较不投／现金等价物，含未来投入option；长周期机会与风险支持进一步讨论，现金越少标准可能越高，结合已有组合和市场，无固定现金线 |
| 流动性需求及约束 | 原文未明确，不填默认值 |
| normal value质量要求 | 业务要懂、明确优势/护城河、无红线、未来FCF可大致估计且有较好IRR；相对compounder/spawner主要可能缺广阔长期再投入空间 |
| FCF与未来经济结果 | 报表已扣增长再投入可能低估创造能力；不能一概加回，可判断未来合理盈利；不精算DCF仍需懂理念 |
| 经济经常性 | 收入持续性/低维持成本是长期FCF的表现，不是表面必要标签；携程场景锁定需验证忠诚、支出、维护成本和佣金条件 |
| 预测置信度 | 主要FCF对未知低容忍；已知公司信息/加直接前瞻/加有前提桥接的类比为大致层次，不机械量化；调研修偏差，对标不搬结果 |
| reverse IRR | 当前估值反看EPV折价或隐含增长，说明前提，不编统一公式或把隐含要求当事实 |
| 研究路径与深度 | 相对标准立项后列FCF关键未知，重点初步研究，对更重要问题深入；目标是尽可能清楚的大致现金流判断，过程中可正常Too Hard/Reject以避免错误投入 |

原文已表达的要求不再标成完全未知；它没有规定的参数也不补。算法、边界和张力见[开放问题](open-questions.md)，本轮只核对理解，不生成计算工具或组合规则。
