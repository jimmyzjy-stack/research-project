# 估值

> 状态：助手提供的通用问题与口径参考，尚非用户确认的投资方法。使用前读取[长篇框架](long-form-investment-framework.md)与[投资 ontology](../investment-ontology.md)；其中的措辞不能替代用户对概念的具体解释。发现差异时记录张力，不擅自选择默认方法。

先确定方法是否适合业务，再收集输入；缺关键数据时交付假设与数据缺口，不编造目标价。

1. 固定估值日期、币种、单位、报告期和价格时间；区分企业价值与股权价值。
2. 选用能解释经济实质的简单方法：盈利或现金流倍数、现金流折现、资产价值等。说明为何适用及主要局限。
3. 建立悲观、基准、乐观情景，分别说明增长、利润率、再投资、股数、净债务、分红及退出估值的假设。
4. 将公司价值换算为稀释后的每股价值；同一笔现金、债务、回购或分红不能重复计入。
5. 分析价格隐含的预期和最敏感的变量；比较不同情景，不只展示单个目标价。
6. 回报计算注明现金流日期、费用与税的处理。只有一次买入与一次终值时可用年化回报；存在中间现金流时按实际时点计算 IRR。多次正负转换可能有多个解，不能强行给出唯一数字。

安全边际和回报要求由用户确定。计算必须能从输入复算；证据编号指向原始数据，假设与事实分开。尚无真实计算需求时不预先搭建计算库。
