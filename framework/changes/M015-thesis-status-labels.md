# M015：简化thesis版本状态命名

日期：2026-10-30。直接反馈见[M015原文](../materials/M015-2026-10-30-thesis-status-labels.md)。

按Jimmy要求，将[Architecture Alignment Report](../../architecture-alignment.md)中的三种状态统一为“待审阅”“继续验证”“已确认”，并同步初步研究产出、G2及[behavioral eval预期](../../evals/behavioral-eval-expectations.md)的用词。

此前报告中的命名依次为“待Jimmy审阅”“已审阅，继续讨论/验证”“Jimmy确认当前版本”。本次分别改为“待审阅”“继续验证”“已确认”；“继续验证”不再附带Jimmy已经看过的含义。“已确认”仍须对应Jimmy明确认可的版本及日期，新版本不自动继承确认。

本次是状态命名的局部确认，不表示D1–D4、整份架构或8类行为预期已获确认。原始理念、历史材料、当前AGENTS与候选、Skills、公司及组合状态均未修改；未运行behavioral eval，也未生成最终AGENTS。
