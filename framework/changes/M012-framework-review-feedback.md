## 本轮改变了什么，为什么会影响决策

| 核对项 | 旧理解的不足 | 当前修订及实际含义 |
| --- | --- | --- |
| 2：价值/回报 | FCF折现价值锚保留，但未充分识别报表已扣的增长再投入 | 区分现金创造与管理层增长再投入，避免低估成长企业；不一概加回或省掉增长成本。可以不精算DCF，但必须理解其理念 |
| 3：结论与normal value | “Reject也算结果”可能仍把否定当特殊豁免，“普通”可能降低质量 | 扎实客观分析后的Reject/Too Hard/推进或深入通过建议买入均属完成；normal value也需理解、明确优势/护城河、无红线、可估FCF及较好IRR，主要差别可能在长期再投资跑道 |
| 4：生意和经济结果 | 容易要求当前报表有利润，把经常性/低维持成本当表面必要条件 | 可以研究充分发展后的合理盈利；收入持续性与维护代价按未来FCF实质判断。携程场景锁定条件链完整保留，海外类比不可直接当国内事实 |
| 5：治理 | 将风险/警惕拆成三类，翻篇后研究内容不够具体 | 合并风险/警惕，实锤红线另列；关键背景实质变化可回风险中性，仍查改善、监控及纠正机制，可能需公开/一线证据 |
| 6：投入回报 | 跨期评价方向获认可，但不同业务阶段未展开 | 咖啡店约半年进入常态非回本承诺；腾讯1–2年探索/约3年考察盈亏非固定截止日；必要时关停无前景业务 |
| 7：懂与置信度 | 主要现金流的重要性和预测依据的距离未明确 | 越关主要FCF越低未知容忍；自身已知→加直接前瞻→加有前提桥接的类比，是大致层次。调研修偏差，类比不搬结果，非机械来源评分 |
| 9：下行 | 即使说成“参考”，0 IRR仍使表达僵化 | 当前目标改为主要持仓在极端情况下避免显著永久损失；旧0表述只保历史，不再作通用门槛，也不扩成任何极端均零损失保证 |
| 10：估值视角 | 正向EPV/成长/option理解获认可，缺反向检验 | reverse IRR从当前估值反看EPV折价/隐含增长；需说明前提，未指定统一公式或唯一解，不把隐含要求当未来事实 |

## 确认了什么，仍没确认什么

- 用户明确认可第4项的双要素、第5项的翻篇含义、第6项原理解、第10项整体理解，并给出相关限定/补充；其他所述项按纠正或补充记录。
- 第1/8/11/12项本次未单独反馈。不把其中原文原则已说过与核对稿全部重述已确认混为一谈。
- 本轮新措辞仍是助手依据反馈的解释，不自动称“用户已逐字确认”。整体长篇框架和ontology稳定确认、最终AGENTS提炼授权均未发生。
- M011中从Timee归纳的10项候选方法，仍不因本批框架反馈自动获得通用规则身份；现有案例原文和当时解释保持历史状态。

## 概念、张力与个案边界

B仍保留24个编号，扩展B001/B002/B004/B005–B009/B010/B012/B013/B015/B016/B018及相关解释。新增C031（FCF创造/增长再投入）、C032（预测依据置信度）、C033（reverse IRR），共33个概念；不建立新技术结构。

旧张力编号不删除：T004的增长/维持投入和正常化由M012补现金创造视角及阶段；T006/U007的治理处理更新为两类与风险中性后改善机制；T007/U009补主要FCF和置信度层次；T005/U002的旧0 IRR表达由最新永久损失解释更新。它们的方法不是重新待答的问题，具体业务证据仍在研究中形成。

需保留而不能替用户抹平的取舍：未来合理盈利不等于任意乐观正常化；选择性增长再投入可以解释低报表现金流，却不能无成本计成长；更多预测资料可以提高理解，但不能把主要FCF不可估计的问题包装成可算。携程国内归属、忠诚来源、维护成本和论文适用性尚未核实；没有据此新增公司估值。

本轮新增人工理解检查，未写测试程序、模型、自动化、Skills或持仓。原始材料/附件、临时AGENTS及代码保持原样。原话、快照、链接、概念编号和修改范围在交付前检查；自动文件检查不能证明投资理解正确。
