## 通用主题入口（未确认的问题清单）

下列文件用于提示可能需要研究的问题；具体投资含义与适用方法由长篇框架和 ontology 中的用户材料确定。助手草案见[初始原则记录](drafts/initial-scaffold.md)。

| 维度 | 要回答的问题 |
| --- | --- |
| [投资哲学](investment-philosophy.md) | 我为什么投资，我有哪些边界？ |
| [行业分析](industry-analysis.md) | 利润池、周期和竞争结构怎样变化？ |
| [业务分析](business-analysis.md) | 谁付钱、为什么付钱、钱如何赚到？ |
| [生意特性与财务](business-quality-and-financials.md) | 增长能否变成可分配现金，资本需求多大？ |
| [护城河与竞争优势](moat.md) | 优势是否真实、可持续，并体现在经济结果上？ |
| [管理层与治理](management-and-governance.md) | 资本分配与激励是否保护长期股东？ |
| [风险](risk.md) | 哪些情况会造成永久损失或使判断失效？ |
| [估值](valuation.md) | 价格隐含什么，每股回报对哪些假设敏感？ |
| [仓位管理](position-sizing.md) | 个股风险如何影响整个组合？ |
| [证据标准](evidence-standards.md) | 结论依据什么，如何追溯与更新？ |

具体公司分析保存在公司 thesis；能够泛化的规则进入长篇框架，并保留对应案例及适用边界。不要为了让主题文件看起来完整而编造用户立场。
