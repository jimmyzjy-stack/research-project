## 2. 首次实际回答正文

放回那个时点，我的初步判断是：**Kaspi值得围绕资本配置做重点研究，但目前这些信息还不足以支持买入。最重要的问题，是哈萨克业务创造的现金，经过收购与后续再投入后，还能为每股股权留下多少价值。**

以下按“2025年收购完成、停息已经获知”的情景推演；你提供的背景作为输入，不带入后来经营结果。已有10月立项包含年内更晚的信息，不能全部倒推成当时已知。

**停息首先改变了需要验证的投资逻辑。** 如果原来的理由包括“核心业务很好、价格不高，并且持续把现金返还股东”，现在最后一环需要重审。首先要核实停息原因及现金去向：是收购付款、土耳其后续建设，还是核心业务自身的资本需求或盈利压力？不能仅凭两个事件同时发生就认定全部原因。

你提供的历史资料里，一份收购前的外部基金模型，既假设不发生国际扩张，又把高现金回报纳入预期收益。因此，原来的回报数字不能直接沿用。但停息也不自动意味着损害股东：若再投入能创造有依据的高回报，股东可能更受益；若只是不断补贴缺乏优势的新业务，原来便宜的核心生意也可能被拖累。

**管理层的过去值得认真看，但要拆清楚成功来自什么。** CEO推动零售银行转型，是比“来自Baring”更有分量的经营经历，值得研究其产品判断、组织和执行能力。董事长处理哈萨克政商关系，可能帮助理解本土经营条件，也提示部分优势具有地域性；这本身既不是治理红线，也不是安全保证。

关键是：过去的成功，有多少来自可迁移的技术、组织和风险管理能力，有多少依赖当地的用户—商户网络、竞争格局及制度环境？**能够把哈萨克的银行做成好生意，不等于已经证明能够从土耳其电商入口再造同样的生意。** 必须解释当地用户和商户为什么选择它、竞争者为什么难以分走收益，以及支付和金融服务究竟如何接起来。

这时我会把初步研究集中在三个问题，并按结果重新排序：

| 优先问题 | 真正影响投资判断的地方 |
| --- | --- |
| 土耳其扩张凭什么获得好的增量资本回报？ | 看收购价格、既有业务经济性、当地竞争，以及真正能移植的优势；不能用“大市场＋super app复制”代替论证 |
| 还要投多少、多久、什么情况下停止？ | 看后续资金需求、融资与担保、阶段目标和退出纪律；不要求经营结果精确可知，但要能大致判断失败会损失多少，是否持续侵蚀核心业务价值 |
| 哈萨克业务能持续产生多少股东可得现金？ | 分开支付、电商和信贷，扣除真实资本需求与信用损失；银行存款、账面利润或现金余额不能直接当作可派给股东的自由现金流 |

下一步先查当时的收购文件、财报和停息说明，做一张简单的资金去向表，再查土耳其竞争与业务机制。访谈应补公开资料无法回答、且真正影响判断的缺口，不先铺开大量研究。

**估值上，我会先问：不依赖土耳其成功，这个价格是否仍然值得买？** 以理解充分的哈萨克核心业务为锚；土耳其尚未证明的成长暂不给额外正价值，但它可能消耗的资金必须计入。不能一边说“土耳其只当免费option”，一边忽略它继续花掉的现金。已支付的收购款反映在收购后的现金、负债和股权中，不能再作为未来支出重复扣除。

由此会得到不同结果：

- 若土耳其没有成功也不会造成难以承受的价值损失，而核心业务在当前价格下已经提供有吸引力的回报，可以继续推进买入研究；不必等海外业务完全成功。
- 若投资必须依赖土耳其成功，才需要对当地优势、盈利路径和投入回报形成足够理解，不能凭CEO履历给成功随意赋一个概率。
- 若持续投入和核心业务现金去向始终无法合理判断，关键股东现金流就可能属于Too Hard；若能够判断、但回报不够或资本配置不可接受，则是放弃当前机会。两者应分开。

所以，**我会先推进有明确问题的初步研究，而不是立即判定Reject或Too Hard；研究价值已经出现，资本吸引力尚未得到证明。** 缺当时价格和上述关键证据，现在不报IRR，也不建议仓位。如果当时已经持有，停息会触发重审，但不自动等于卖出；同样不能沿用旧派息模型继续建议加仓。最终还要与持有现金及当时其他机会比较。

## 3. 本轮Research Planning工作记录

这是历史测试的工作规划，不是创建真实公司的正式research state。以下排序是Main的暂定研究选择，不冒充Jimmy已确认的研究范围。

| 字段 | 当前工作内容 |
| --- | --- |
| research question | 土耳其回报未兑现甚至失败时，收购及后续资本配置会怎样改变哈萨克核心业务可归属于股东的未来现金流和每股价值？ |
| why it matters | 停息改变原有现金返还路径；若海外可持续吸走核心现金，不能把本土估值与海外风险完全隔离 |
| impact on value / decision | 决定能否不依赖海外成功而投资、哪些增长可计价，以及是否因关键现金流难估而Too Hard |
| current belief | 海外可能扩展跑道，也可能毁损价值；CEO本土经营经历是值得检验的正面线索，尚不足证明跨国复制。停息与收购的完整因果待核 |
| uncertainty | 收购条款/融资、后续投入范围与节奏、资本配置纪律、土耳其真实优势和核心可分配现金均未完成当时原始披露核验 |
| existing evidence | M020情景背景；M017:S006提供后续资料定位；S012是收购前的第三方观点对照。并非三份独立验证 |
| evidence needed | 截止当时的收购及融资条款、停息说明、分部与监管资本披露；目标业务的单位经济性/竞争与投资计划；董事会资本配置约束及实际执行记录 |
| whether public information can answer it | 条款、历史投入、财务与正式政策应先公开核查；管理层目标仍需与经济机制和执行交叉检验，口头“有纪律”不足 |
| whether offline research is needed | 若公开材料仍不能解释客户选择/商户经济性、竞争响应或组织执行，再定向访谈；当前不预设必须大范围线下调研 |
| current research priority | 首轮最高价值未知；若查明海外资金风险有限，优先级转回本土护城河、可持续增长/现金和价格。若停息主因为核心资本压力，也应立刻重排 |

下一最佳研究动作：先复原准确事件日及当时披露，连接“原先股东可得现金→收购付款/融资→后续承诺与实际可支配剩余”，给出方向性区间及无法估计的部分，再决定是研究土耳其增量优势还是返回本土现金创造。不为填模型先造成功概率。

最强反对路线（Main自己的反驳，不是独立Red Team）：本土优势与CEO履历可能使我们过度相信海外复制；即使海外正估值设为零，未来追加资金也可能使本土价值无法兑现。如果缺乏约束的持续投入才是资本配置常态，单独计算本土高IRR会给出误导性的安全边际。反过来，不能因海外尚未盈利就推定其没有优势或必然毁损价值。
