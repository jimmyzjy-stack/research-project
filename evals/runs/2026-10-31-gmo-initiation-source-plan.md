## 2. 暂定业务特定value-driver map（待原件修订）

```text
可服务商户及真实支付需求
 → 接入/活跃商户、同商户使用、实际交易路由份额
 → 有效交易件数与金额（分别看支付方式/场景/客户结构）
 → 初始接入/系统月费/按件或金额计费/其他收入（实际模式待核）
 → 核清principal-agent及上游支付通道成本后，真正留给公司的收入/毛利
 → 持续系统、安全合规、销售/实施/服务、研发等必要成本
 → 经营利润与税
 → 维持/增长软件及其他投入、商户结算资金、营运资金净变化
 → 如存在金融业务，另拆利差/手续费、信用损失、资金成本/资本占用
 → 现金归属、债务/限制、子公司少数权益、母集团配置及稀释
 → 每股股东现金
```

处理金额不是公司收入；商户代收/待结算现金不自动是自由现金；贷款增长若存在，也不能由技术平台毛利率替代资本回报。现有商户×使用和市场量×份额是替代拆法，不能覆盖同层后重复相乘。这些是待验证的分析约束，不表示GMO实际存在已认定的问题。

## 3. 取得原件后主动生成/收窄的候选问题

在基础覆盖前不宣布这就是最终5–10题或确定排序。初步最高价值的基础未知是：**哪种业务、收费与资金机制在创造真正可归股东的现金，如何从报表与交易量中识别？** 这决定后续应优先研究收费防御、增长跑道还是资本占用，不能先假定公司一定属于某一类compounder。
