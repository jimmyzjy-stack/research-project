# 携程中国酒店业务：未来5–10年的护城河问题生成

记录日期：2026-11-01，Asia/Shanghai。用户在此前GMO PG研究暂缓期间要求进行另一项测试。

用户原话：

> 那么先尝试另一个问题的测试：关于携程的中国酒店业务，未来 5–10 年最需要验证的护城河问题是什么？

这是Main使用research-planning形成的实际问题生成输出，不是完整立项、已验证thesis、投资建议或独立盲测。Main已读Jimmy在M012等处对携程场景锁定、国内single-homing、维护成本和佣金的讨论；不能把重新提出这些入口问题计作无提示的历史发现。没有携程完整早期立项包或Jimmy后来问题集，不能评分历史crux命中。

**范围与价值驱动**

默认研究集团中国境内酒店预订，携程、去哪儿等渠道分开观察；集团内品牌之间的转换与流向外部竞争者分开。出境酒店、Trip.com海外增长和集团整体利润率不能直接证明本业务护城河。

工作分解：可服务住宿需求 → 完成入住的间夜及客群/渠道结构 → 酒店成交价与平台实际变现 → 获客、优惠、供给运营、履约、客服、技术等必要成本 → 维持投入、税和营运资金 → 可持续现金流及其持续时间。

可用“完成入住间夜×每间夜净贡献−必要固定成本/投入等”组织判断；不是一份数值预测。每间夜净贡献需统一佣金、营销收费、平台/酒店承担的优惠、退款及总额/净额口径，避免同笔费用重复扣减。不能把集团住宿收入除以随意估计的国内GMV当国内佣金率。

最重要的工作假说是：携程可能持续掌握一批酒店难以绕开、竞争者难以低成本争取的需求，并在维护这项优势后保留经济收益。以下检验这条假说，不预设它已成立。

新增信息的作用：提高酒店外部选择权问题的研究优先级，另把合规条件下的价值获取明确拆出。对携程国内护城河强度尚不足以提高或降低到确定结论。

**Q1｜用户究竟把哪些住宿场景持续交给携程，为什么难被带走？**

当前工作理解：可能由省心、履约/售后信任、供给/条款、会员权益、差旅流程和跨产品便利共同形成选择，单有高复购不足以识别原因。尚未知各机制覆盖多少高贡献订单、是否依赖持续补贴，以及年轻新用户是否会重复形成同样习惯。

重点问：同一用户的全部中国酒店预订中，携程占多少实际成交？高频差旅、低频休闲、陌生城市、熟悉酒店、临时出行是否不同？外部价格或服务改善后，用户转移哪些订单，过一个完整出行周期是否回来？安装多个App和同一订单比价不等于成交多归属；短期单次成交也不等于长期锁定。

FCF连接：实际获取间夜、获客/留存成本、用户价值及优势持续期。支持证据是同等可比条件下持续的主渠道地位，且原因和经济价值可解释；削弱/推翻相应锁定假说的证据是可持续的小幅竞争改善即可使高贡献用户长期转移、复购需反复花钱买回。低价本身也可能源于持久的供给/成本优势，不能把所有价格优势都剔除后才承认护城河。

最佳证据：覆盖完整出行周期的真实订单/搜索—成交记录与分层用户回溯访谈，辅以可复核的代表性交易面板。公开App流量和满意度只能作proxy；关键原因与全部预订分母宜一线补充。若有海外OTA论文，须先查本地价格、渠道、商务采购等迁移条件，不能把海外single-homing当国内事实。

**Q2｜携程为酒店创造了多少难以替代的增量贡献利润，能否长期保住收费？**

工作假说：平台可能带来酒店自行难获取的异地、新客或有价值需求；但佣金可能同时支付真实增量、渠道替代与竞争性曝光，当前拆分未知。

问相同酒店、时期、客群/订单：拿掉携程后，客人会消失、改订另一家酒店，还是通过品牌自有渠道回到这家店？扣佣金、促销、退改、会员和直销获客费用后，酒店各渠道的贡献利润怎样？满房/淡季、独立店/加盟店/直营连锁、高端/经济型的外部选择权如何不同？酒店连锁化、会员及直销增强，会使平台更有价值还是更容易被绕开？

FCF连接：可持续净变现、供给质量/条款及成交间夜。若酒店尝试减少OTA投放后稳定恢复相同利润、并能低成本迁移有价值客源，削弱“酒店难绕开”假说；若带来新增客源/更好入住结构，且酒店自主选择后仍愿支付有经济意义的费用，则支持。不能以华住单一分母推广整个行业，也不能把名义佣金率当全部渠道成本。

最佳证据：不同类型酒店的收益管理/渠道负责人、加盟业主和真实渠道P&L，结合有对照的调整佣金、退出促销或迁移直销经历。连锁年报先建立边界，公开资料通常难单独识别增量性，适合及时交Jimmy一线调研。

**Q3｜供给与服务优势具体是什么，双方多平台使用时为何仍难复制？**

工作假说：有效优势可能在真实可订库存、特定房型/日期、价格/退改、确认与售后可靠性，不只是上架酒店数。未知这些优势是否独有、来自何种成本/规模/合作安排，以及对手达到一定覆盖后差距是否快速缩小。

问同一酒店、房型、入住日和权益：竞品是否能持续提供相同可订性和履约？新增供给是否仍明显增加用户价值，还是常用库存已普遍同质化？供给更好是否带来可持续用户集中，而集中需求又能换来更好的供给条件？PMS/渠道管理系统与标准接口是否降低复制成本？多平台上架本身不能证明网络效应失效，优势亦不能仅由双方数量推出。

FCF连接：转化、复购、净变现、履约损失和维护成本。若同类客群中的关键库存/条款已易被复制，用户和酒店均能低成本转移，削弱独特供给/双边循环解释；若反复存在对手难以经济复制的供给和履约差距，且带来真实交易集中，则支持。

最佳证据：合规的匹配房型/价格/取消条款/库存抽样、真实无法预订或履约纠纷回溯、酒店渠道与系统供应商访谈。跨城市/价位/旺淡季覆盖；不实际占房、制造订单或抓取私人数据。公开样本先确定差异是否存在，差异原因与合同/执行成本往往需一线。

**Q4｜在合规且酒店保有渠道和定价选择权的条件下，优势还剩多少？**

这是初步年报核查后独立拆出的前置问题。当前仅确认S01披露过调查，未确认后续结果；不假定调查针对某项具体合同做法。

检验：价格/流量/渠道约束若受限制或改变，用户是否仍因产品、供给、服务与效率选择携程？酒店是否仍自愿保留供给、支付费用？区分一次性罚款、长期合同/经营规则变化和实际需求受损，不能只在估值里减一笔钱。

FCF连接：长期变现、必要补贴/服务成本与优势期限。支持证据来自合同/规则变化后仍然成立的客户价值和经济结果；削弱证据来自关键供给/收费需依赖不能持续执行的安排。监管变化也可能改善信任或降低某些摩擦，净效应需检验。

最佳证据：SAMR及相关监管/法律原文、公司正式披露、适用合同与真实执行，再访酒店渠道负责人。公开最新状态核实价值高、成本低，应先做；本轮没有完成此项，不把缺口写成已解决。

**Q5｜维持用户和供给优势以后，每间夜能持续留下多少现金？**

工作理解：优势可能同时降低获客/履约成本并提高价值获取，但中国境内酒店业务独立的成本/净贡献尚未建立。集团利润率、海外增长或总销售费用不能直接回答。

需分清维持存量需求所需的获客/优惠、客服履约、酒店合作和技术投入，与真正新增市场/业务的增长投入。若存量高贡献订单越来越依赖补贴、买流量或更昂贵服务，即使GMV和复购增长，经济租也可能下降；增长性投入不能因此一概归为维护费用。关注完成入住、退改和净收入口径，避免重复扣补贴。

FCF连接直接：稳定净变现减必要维护成本的差额与规模。支持是可比较存量客群/城市中，服务质量和份额稳定时净贡献可持续；削弱是维持相同地位需持续抬高现金投入，且不能由暂时竞争/结构变化解释。

最佳证据：可得的分部/渠道经营数据与费用拆分、用户和酒店实际优惠承担、客服/运营流程及单位成本。公开资料做方向性桥接，若拿不到独立口径就保留区间和关键未知，不伪造精确国内FCF。

**Q6｜大流量竞争者能否持续拿走高贡献订单，并打断上述循环？**

检验内容/本地生活/其他OTA的流量是否能转成无需无限补贴的常态酒店交易：从低价券、低频新客到高频/高价值、陌生城市、临时和复杂履约场景，跨越的实际门槛是什么？不要仅比较DAU或成交GMV。携程是否需要长期跟进同等补贴才能维持上述客群？

FCF连接：高贡献间夜、净变现和竞争防御成本。对手在补贴退坡后仍获得这些实际订单和足够供给/服务，削弱保护假说；只有补贴期低质量交易，尚不足以证明击穿。竞品份额增长与携程经济租下降也需区分共同市场增长/客群结构。

最佳证据：可比客群真实跨渠道成交/留存、补贴前后自然实验、酒店分渠道P&L、竞品正式披露。媒体/研究报告发现线索后追原数据；多个引用同一面板的报告不构成独立验证。初研先定位最易被争夺的利润池，确认机制后才深入做长期份额判断。

**Q7｜AI等新入口会把携程的客户关系、收费和履约变成什么？**

条件压力测试，不预设AI必然颠覆。问用户把搜索、比较和交易委托给新入口时，谁掌握客户、价格/库存接口、支付、售后和复购？新入口能否经济地直连酒店，还是需要携程履约/供给，携程又能保留多少净收益？不重复把AI的客服降本与全部收入增长同时乐观计入。

FCF连接：直接流量/获客成本、渠道议价、净变现及履约成本。真实持续的订单迁移、接口/合作条件和交易后行为可支持/削弱具体路径；产品演示、用户讨论量和任意十年概率不足以证明结果。

最佳证据：实际产品全链路能力、公开合作/合同和真实使用/成交；技术能力到商业采用、控制权到价值获取逐段验证。今天对十年终局的可学性较低，先保留条件场景与可观察节点；没有行为变化时，不让AI话题挤占前三项研究。

**优先级与下一单位研究时间**

不建立综合评分。Q1/Q2是最主要的决策crux：分别决定是否控制难争取需求、这种需求能否转化为酒店愿付的现金收益；当前直接证据缺口大，但可以通过订单回溯和一线学习。Q3识别双边循环究竟是否有难复制的机制，须与Q1/Q2相互检验。Q5始终跟随这些机制检查经济结果。

Q4可能实质影响上述基础，且最新公开状态的核实成本低，因此是下一单位公开研究时间的前置动作。完成后据实际规则重排，不以“尚未查新进展”无限延后行为研究。Q6聚焦已识别利润池的竞争压力；Q7影响可能大但今天可学性弱，除非出现具体迁移证据，优先级较低。

当前highest-value unknown：携程是否持续控制一批竞争者难经济地争取、酒店难自行获取的高贡献需求，以及维护这种控制的真实代价。它比平台总用户数、上架酒店数或笼统网络效应标签更接近未来FCF。

初研：核监管/合同边界，做同条件供给与价格检查，回溯用户真实预订，建立酒店渠道增量利润的样本判断。只有这些机制获得足够支持，再深研其客群规模、代际变化、连锁化/入口变化下的持久性和FCF区间。若关键机制明确不成立，结束相应假说；若主要现金来源经过现实可行研究仍无法判断，可Too Hard。不因一份数据缺失或一次访谈就机械Reject/Too Hard。

及时交Jimmy的一线brief：用户端覆盖差旅/休闲、频率/年龄、熟悉/陌生城市和不同酒店价位，回溯真实最近预订与放弃订单；酒店端覆盖独立、不同连锁、加盟/直营、不同城市和入住率，询问实际渠道调整及贡献利润。用行为和对照提问，记录招募、业务量、利益、时期及选择偏差；不设统一访谈人数过线，不直接外推行业，不自行联系受访者。
