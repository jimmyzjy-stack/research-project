# 历史早期材料回放：通用Main方法（冻结执行输入）

这不是历史答案。只使用任务明确允许的资料，不能读取本项目后续公司讨论/参考问题/结果；历史输入中的分析和管理层主张也不是已核实事实。不联网补后来的数据，不用记忆中的后续经营结果作事实。观察边界以input.md说明为准。

1. 建立简洁立项：business model、industry/value chain、business traits、moat机制、TAM/growth、competition/share、volume-price、profit/FCF、management/governance/capital allocation、valuation snapshot、risks/unknowns。按业务合并组织，少数关键机制讲透，不按格式机械填表，不复制长履历或打分。
2. 从业务建立公司特定value-driver map：谁付费/为什么→可服务需求/用量→量价/份额→收入→成本/利润→维持与增长投入/营运资金/融资或监管资本（如适用）→股东每股现金；优势期限、资本配置和稀释改变路径。简单因果图或可读公式即可，不要求完整DCF。
3. 对重要节点问：Base Case必须什么成立（没有现成Base就写有待验证的工作假设，不造预测）；未知是什么；长期FCF/价值对谁最敏感；谁可能错；什么能证伪；市场似乎相信什么及其证据（没有证据就不声称市场共识）；什么观察能实际解决。
4. 生成并保留最重要5–10题（本次评估要求，不是所有研究永久条数限制）。每题具体到业务机制/可观察变量/成立条件/投资影响；说明why matters、FCF节点、belief/uncertainty、strengthen/weaken/falsify、最佳evidence/source、公开可答范围与是否线下，不必一题一张大表。
5. 三轴排序：decision sensitivity、uncertainty、researchability/expected value of information，不加权总分。区分初研先做什么、什么只有前提成立才值得深研；最高价值未知不等于容易查的问题。
6. 输出Proceed/Reject/Too Hard或有具体补证路径的暂缓结论与依据；Proceed只是值得继续研究，不是买入。缺价格/FCF不造IRR；静态收益率不是IRR；来源/股数/币种/期间明示；实际持仓未知。
7. 指出下一单位研究时间做什么、理想证据和可行替代、及时给Jimmy的线下brief。研究后应重排、保留已解/重开条件，不扩大无止境清单。
8. 证据独立性按共同原话/数据/模型判断，不按来源数量。新观点/问题是待验证推断，不是新事实；猜测不能写成后续已发生。

立项报告和问题输出分开呈现：先立项及当前driver map，再有序问题、初研/条件深研、highest-value unknown及next action。标明哪些问题输入已写、哪些是你新增的机制深化。引用input的P/T位置；若未看DOCX图片，明示这一覆盖限制。
