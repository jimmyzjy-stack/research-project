# 研究质量检查

逐项回答“通过／缺口／不适用”，附文件位置、证据编号或理由。

先按[框架理解检查](framework-fidelity.md)确认是否忠实使用用户已经明确的概念和判断。以下是临时研究检查，不将尚未确认的风险定义、护城河理解或估值方法当作用户原则。

| 检查 | 合格的表现 |
| --- | --- |
| 公司身份 | 公司、交易所、证券代码、股份类别和报告币种没有混淆 |
| 研究范围 | 说明资料覆盖至何时，以及初筛或深入研究的实际深度 |
| 事实与来源 | 关键事实有可定位原始资料，日期、期间、单位与口径明确 |
| 事实与判断分离 | 推断有推理路径，预测和假设没有伪装成事实 |
| 业务理解 | 能解释客户为何购买、现金怎样产生、资本需求怎样影响增长 |
| 优势检验 | 护城河机制有经济结果支撑，也检查了竞争反证 |
| 风险与反证 | 按用户已明确的风险含义分析，有最强反对意见和可观察的失效条件；未知取舍保持未知 |
| 估值可复算 | 数据足够时展示方法、假设、口径与情景；不足时明确未计算 |
| 未知项处理 | 缺口按影响排序，给出验证方法；不靠捏造数字补齐 |
| 行动边界 | 研究结论、建议与实际持仓分开，未设定偏好没有被默认为已确认 |
| Question / Evidence / Source Plan | 有明确FCF/decision问题，先定区分证据再主动找最适来源；没有关键缺口不无限研究 |
| Claim适配与来源依赖 | “说过”/现实分开，按Policy十维说明支持范围；同原话/采访/数据/模型不互证，AI/声誉不加独立证据 |
| 代表性与迁移 | 访谈/数据样本、分母、方法/时期和论文external validity/transfer assumptions明确，关键连接不跳过 |
| 证据综合与及时线下 | 解释原belief/替代解释、新证据依赖及机制/FCF/confidence改变；公开残余缺口及时给Jimmy调研brief |
| 研究信息价值 | ability to learn、继续工作的收益/成本与停止/重开条件清楚；缺证据不造confidence，不因一次不可访问永久Too Hard |
| 立项质量 | 13项逻辑建立而非标题齐全；时点/口径有依据，机制、价格/风险与研究去留清楚，深度合理、少复制履历/打分 |
| 主动问题生成 | 没有用户具体问题仍能从公司特定value-driver map推导must-be-true、敏感/易错假设、可证伪/可取证问题，非搜索摘要或宽泛问句 |
| 三轴与循环 | 分decision sensitivity、uncertainty、researchability/信息价值排序；初研/条件深研分开，研究后重排已解/信心/新题/最高未知及下一单位时间 |
| 历史与思路独立 | 后续问题/结果不向生成者泄漏，已有提示与新增深化分开；思路重合不是独立证据，不能把已知答案的Main重答称盲测 |

关键证据缺失、身份错误或事实捏造是阻止相应结论成立的缺口，不能被其他项目通过抵消。此检查评价研究过程，不保证投资结果。

M022新增检查依据[Source & Evidence Policy](../framework/source-and-evidence-policy.md)，对应BE16–BE24。人工审阅与实际回答应另记录，不用文件存在或预期文档替代运行验证。

M023核心能力另按[历史评估协议](historical-question-generation.md)与[立项方法](../framework/initiation-and-question-generation.md)人审；缺后续参考不评价历史命中，少量首轮运行不宣布稳定可靠。
