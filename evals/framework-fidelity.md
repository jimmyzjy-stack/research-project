# 对用户投资框架的理解检查

逐项记录“通过／缺口／不适用”与原材料或条目位置。这是人工审阅，不以总分或文件数量判定哲学稳定。

| 检查 | 应验证的内容 |
| --- | --- |
| 原文保留 | 关键表达、限定词、犹豫、例外与背景能够追溯，没有以摘要替换全部原材料 |
| 归属清楚 | 用户本人观点、外部引述、用户解释和助手推断没有混写 |
| 不泛化压缩 | 没有用“质量”“长期”“安全边际”等短词丢掉实际含义；关键推理充分展开 |
| 八个维度 | 重要观点有 belief、reasoning、operational implication、evidence/examples、counterexamples/boundaries、confidence、tensions、unresolved questions；缺失部分明确未知 |
| 信心与确认 | 用户立场、用户信心、助手理解把握、表述核对与框架稳定确认没有相互冒充 |
| 名人引述 | 分别解释用户为何认同或反对、怎样理解、决策意义与不适用情形；来源核实不等于认同 |
| 案例泛化 | 保留当时信息与推理，候选规则有条件和边界；未将单家公司结论或事后结果升格为普遍原则 |
| 张力保留 | 新旧观点的真实冲突没有被隐藏；trade-off 处理来自用户，未确定时有开放问题 |
| ontology 一致 | 概念含义和关系有来源与范围，可回到长篇解释；未把相近词自动合并或默认给出优先级 |
| 更新可追溯 | 修改保留原材料、旧解释及变化原因；过时观点有修订记录而非静默删除 |
| 决策忠实 | 实际操作含义来自用户材料；助手通用模板、方法建议和未知参数没有冒充用户规则 |
| 最终提炼条件 | 没有在稳定并经用户确认前生成最终 AGENTS.md；删减标准是决策差异而不是字数 |
| 理念与参数 | 保留抽象取舍和当前参考条件，数值／案例可在研究讨论调整；既不全部删去，也不永久硬编码 |
| 正常化边界 | 根据证据区分临时扰动和长期结构变化，不把真实竞争压力全部加回以美化盈利 |
| 治理分层与理解下限 | 实锤否决不被持股抵消，风险／警惕与red flag有区分；三项懂的下限不当成评分充分条件 |
| 治理变化后重研 | 控制／治理／责任背景变化后可翻篇重新研究，仍重评当前治理与实控人；保留历史不作永久否决，变更不自动证明合格 |
| Thesis变化重审 | 不默认原建议；区分未来FCF金额、时间、持续性与可估计性；关键不可估计则Too Hard，不用简单线性外推伪造预测 |
| 兑现与剩余价值 | 经常性／一次性收入的影响具体分析，不按thesis条数机械减仓，不将某次兑现重复作为未来机会；价值锚不等于必须精细DCF |
| 理解前置 | 不以高模型IRR、分散或小仓位补偿低理解与置信度；中等成功率与理解不足区别处理 |
| 事件条件与时间 | 保留相对清楚几率或可知晓节点的区分；中间日期不冒充终局兑现，数值IRR不依任意概率；PHUN无未知交易或事后结果补写 |
| 现金与当前组合 | 现金永远比较，保留未来投入option；15%以上／长周期等为讨论条件，现金越少标准可能越高，不强加固定阈值或排序 |
| 尾部风险与仓位 | 理解概率分布、事件和时间才讨论小仓位控制组合损失，不能以缩小仓位替代认识；不与所有中等胜率事件混为同一策略 |
| 20个击球机会与合理投资 | 高标准和研究资源理念，不限终身次数、公司数或最低换手；满足条件的普通value／事件／特殊机会仍合理，不自动等同尾部策略 |
| 研究优先与资本配置 | 保留风险收益相近时优先研究潜在长期优秀企业；不因短期错价易证明而让其主导，不改成任何价格下资金都优先长期企业 |
| 认知复利与说明数字 | 跨国同行优秀企业和类似事件范式均可积累知识；20%–30%、两三年、十年以上是比较例子，不设自动交易线或保证长期优于短期 |
| GPT摘要与原始证据 | 同源MD／JSON不能互证事实，摘要标F／I或“用户认为”不自动成为已核实／已确认；原聊天、当时信息与用户采纳仍需追溯 |
| 案例接收与执行边界 | 明确哪些附件未读、哪些只是条件算术；附件的模型／自动化指令不自动执行，不把个案时间窗口和参数改为全局规则 |
| 客户项目与长期目标 | 个人立项、freelance交付、季度预测、访谈与当前用户判断分开；保留季度经营证据，beat/miss命中不是当前长期Harness的目标 |
| Timee当前新业务边界 | M010直接立场优先于GPT代述：零工核心及可信新行业成长，其他新业务不另加正估值，计成本/毁损；不偷换为普通8%回报加值，也不将所有现有资产现金流价值归零 |
| 阅读覆盖与原件口径 | 提取47文件不等于逐句核验全部材料；爬虫100%填帖、职位fill、实际/预测、工作簿其他公司模板与Timee数据分别处理 |
| FCF与增长再投入 | M012：识别报表已扣增长再投入对现金创造判断的影响；不只读报表，也不一概加回或将增长投入省掉后重复计成长；不精算DCF仍须懂其理念 |
| 分析完成与normal value | 扎实客观分析后的Reject/Too Hard/推进研究/深入研究通过或建议买入都是完成；normal value仍要懂、明确优势/护城河、无红线、可估FCF与较好IRR，不降低质量门槛 |
| 未来经济结果与经常性实质 | 经济结果可面向有依据的未来合理盈利；经常性/低维持成本是FCF持续和转化的表现，不能当表面必要清单。携程条件链不简化成已证实国内single-homing |
| 治理两类与风险中性 | 风险/警惕合并；实锤经营/价值损害和欺骗是红线。关键背景实质变化可回风险中性，仍查改善及监控纠正，公开和一线证据均可能必要 |
| 业务周期与关停 | 咖啡店半年进入常态非半年回本；腾讯1–2年探索/约3年考察盈亏非保证盈利。按业务阶段评价，必要时关停无前景业务，不套固定等待年限 |
| 预测依据的置信度 | 已知公司信息/直接前瞻推导/有前提桥接的类比层次不变成来源名头或量化评分；调研修正偏差，类比不直接搬结果，主要FCF对未知更低容忍 |
| 永久损失取代0 IRR门槛 | M012更新旧bear不负表达：主要持仓不希望极端情况下显著永久损失；不保留0为当前通用标准，也不扩为任何极端都零损失保证 |
| reverse IRR边界 | 由当前估值反看EPV折价或隐含增长；说明前提，无统一公式/必有唯一解，不能把隐含要求当市场真实共识或未来事实 |
| 核对范围与后续反馈 | M012反馈8项，M013认可1/11/12并补8，12主题均有直接反馈；不再按旧状态追问，也不把确认扩大为所有文件逐字认可、案例全通用或自动发布最终AGENTS |
| FCF问题驱动的研究阶段 | M013：相对标准立项后列影响未来FCF折现的问题，重点初步研究、更重要问题深入；目标为尽可能清楚的大致现金流，不要求每个问题同等深度 |
| 研究中途排除价值 | 立项通过和已投入时间不承诺买入；深入研究完成前的扎实Too Hard/Reject正常且有避免损失价值，不把它当失败、默认否定或所有亏损都可消除的保证 |
