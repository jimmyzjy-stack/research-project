## 4. 本轮回到原件发现的具体问题

### 4.1 评论是机制线索，编码与统计仍需核对

本轮按存储单元格直接计数，审阅部分原评论和编码，结果见[计数记录](../framework/materials/M017/survey-count-audit.json)：

| 可定位事实 | 可以支持什么 | 不能推出什么 |
| --- | --- | --- |
| 评论分析B2:B294有293条非空评论，第一条B2为明显跑题的个人来信 | 档案覆盖了293条文本；需要区分有效研究样本 | 293个有效消费者、全国代表性或293个独立家庭 |
| 用途场景M2:M294实际204条非空；场景频次统计B12公式为整列COUNTIF，缓存205，包含M1表头 | 当前场景记录分母应先排除表头；原缓存205不等于205条有效场景记录 | 无需检查就把GPT整合稿中的“205条”当已核事实 |
| 自饮/家庭聚会各68、送礼53等频次可在存储标签中复现；多选且有嵌套关系 | 对当前人工标签作描述；68/204约33.3%只是样本标签频次 | 相加当独立需求、全国场景份额或每人年开瓶量 |
| 覆盖率表“一年用量”缓存272；当前K列排除表头实际非空128，N/O/P也有缓存与当前内容不一致 | 缓存可能过期或处理过程变动，必须回原内容/公式核对 | 将缓存的高覆盖率当资料充分；本轮没有重算整个Excel引擎 |
| B3是1月以来买货/送家人，自己基本不饮酒；K3记“4箱”；B3写精品2箱，O3却写精品4箱 | 新购买者可能不是新饮用者；观察期、编码和品种数量有误差 | 年用量4箱、净新增饮用4箱，或可靠的总体消费推导 |
| B10旧用户主要家用/送礼、佛系申购未买到，O10却填了购买数量；B76明确提出应另看不买的原因 | 需区分历史购买、当前申购、成功购买和未购买者；存在反向抽样需求 | 所有编码购买量都是i茅台新增成交，或沉默人群同样有意愿 |

原Excel不改。精确文本未重复不代表已完成去重到人/家庭；没有重新编码全部293条，更没有据此给需求点估计。样本较适合发现“保真/获取成本”“场景/角色”等机制、设计反方访谈，不适合估算总体渗透率。

### 4.2 管理层陈述与支持到哪一步

S005/L66–68称合同负债受直销、打款和代售变化影响，并称库存健康；L78给i茅台收入/注册数。它们提出可查的口径和机制，尚不能独立证明终端开瓶、全国库存持续去化或复购。

S005/L13也谈及增加品牌建设和市场费用。即使厂商回收了渠道价差，也要看新承担的品牌、履约、渠道服务与资本投入后，FCF是否真正改善。不能把渠道商过去全部毛利直接加给公司。

### 4.3 GPT模型建议也要审计

S003/L79–86把“公司产品出货”与包含酒厂库存的“全系统库存变化”桥接。边界需重设：如果起点是公司sell-in，应桥接公司外渠道/家庭等库存；若包括酒厂库存，起点可能需要是生产/可供货量。另需处理损耗、出口等口径，不能把这个示意式直接当可计算恒等式。

M018:S003/S004已为部分历史经营/估值假设提供原工作件支持，包括4%零售提价、2031 PE25和分红再投路径；局部条件算术约11.14%与原缓存一致，非全模型重算。2026 ASP约−5%的具体一轮、2024的1250/约15%及1340元对应版本仍未复现。非标分母、终端价/确认收入价和各轮模型日期必须分开；不据旧数反算当前回报，也不自动采用GPT分级仓位/国家门槛建议。

## 5. 初步研究的两个核心问题

下面是Main基于本轮直接问题提出的**工作计划**，不是Jimmy已确认的新thesis或资本结论。两个问题同属高优先，按能消除的关键未知持续重排，不为流程重复已解事项。

### M-Q1：长期需求是否足以支持可持续的核心生意？

| Planning信息 | 当前工作记录 |
| --- | --- |
| research question | 高端白酒真实消费场景、人群、频次如何长期演变；茅台在其中的选择率/单次用量能否抵消或超过场景变化？ |
| why it matters | 决定未来收入基础和现金流持续年限；高品牌份额不保证需求池不缩小 |
| impact on value / decision | 若主要需求长期衰退或无法方向判断，会改变增长、earnings power或可估计性，而非只改终值倍数 |
| current belief | 现材料能提出机制与多种假说，尚不足以确认长期需求solid，也不足以判定必然衰退 |
| uncertainty | 场景/行业缩小、份额变化、渠道/家庭库存、代际与年龄效应混杂 |
| existing evidence | M017:S004评论/编码、S005公司陈述、S002历史重建；M018:S002原计划、S005消费者报告、S006–S008跨国数据及S025原帖截图，均按各自范围使用 |
| evidence needed | 同口径消费/供给/库存；减少购买与未购买者；真实近期使用、替代酒、付款/购买/使用角色及库存变动 |
| whether public information can answer it | 先核行业/公司量价、生产销售滞后及人口/收入原始统计；公开数据未必能直接给开瓶与场景选择 |
| whether offline research is needed | 对残余场景、动机/替代、开瓶与库存缺口需要分层访谈/渠道旁证；不能只访问酒友或茅台镇相关人群 |
| current research priority | 高；先确定“需求池变动”和“茅台场景内选择”能否分开观察，作为highest-value unknown候选 |

### M-Q2：长期提价能否落到公司可留存的FCF？

| Planning信息 | 当前工作记录 |
| --- | --- |
| research question | 在真实场景、供给和竞争条件下，茅台能否持续提高净实现价，并在必要维护投入后提高长期现金创造？ |
| why it matters | “贵、买得起、品牌强、公司涨出厂价”分别都不等于长期经济定价权 |
| impact on value / decision | 改变ASP、销量弹性、结构、费用与利润持续性，关系估值和能否继续研究至投资判断 |
| current belief | 品牌共同认知、保真/搜索成本是待验证机制；当前没有足够证据给长期提价率 |
| uncertainty | 净终端价格/批价/出厂价不同，渠道租金回收与真正愿付价增长混同；非标升级、竞争、政策/场景变动 |
| existing evidence | M017:S005价格/渠道陈述与S004评论；M018:S001原立项、S002价格问题计划、S003/S004历史价量/模型及相关制度论文；未核部分不当成已证实定价权 |
| evidence needed | 四层价格与销量/结构的同口径历史，真实选择与替代、支付意愿和复购，回收价差后的新增维护成本 |
| whether public information can answer it | 可先建价格层/产品/渠道定义和财务桥接，拆单品牌与集团的量价；海外类比只能提供机制和反例 |
| whether offline research is needed | 需要时针对同一场景的选择、替代容忍、实际付款价、送收礼双方展开，避免“未来愿不愿买”的泛问 |
| current research priority | 高，与M-Q1联动；不先把+4%等旧增长率当答案，具体先后随证据价值变化 |

**Next best research action：**原研究包已补齐，不重复要求获取立项/计划。先把现有宏观数据、消费者调查、原帖与价格/渠道/库存映射到两个核心问题，明确哪些未知已回答、哪些仍需单品牌对标原数据或一线行为证据；相关模型修订按具体缺口推进。线下调研不预设30–40人或特定地点；主要需求/定价仍无法方向判断时，保留限制并可形成Too Hard/Reject，不用高模型IRR填补。

## 6. 对未来评估的用途

适合检验：注册/渠道销售能否被错误升级为净新需求；可负担性是否被当增长证明；单品牌是否被套集团CAGR；评论缓存/编码能否被审计；渠道价差是否被重复加值；短期结构修正是否污染长期判断。

本轮Main已经看过重建稿最终方向，不能宣称blind或完整历史时点回放。后续可用原始评论/纪要的有限片段构造证据题，先保留独立回答再开放重建结论，准确注明原聊天和其他原件缺失；当前不把这些候选任务标为已运行/通过。最终AGENTS继续暂缓。

M018新增的原计划、截图、CSV定义、论文题名错配和工作模型，可进一步做有限原始材料测试，见[本轮核对](CASE003-M018-source-review.md)。它们增加证据覆盖，不自动证明长期需求/提价已solid、历史thesis已确认或独立评估已通过。
