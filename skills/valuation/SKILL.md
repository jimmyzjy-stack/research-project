# 估值与回报分析

> 当前为临时通用流程，尚非用户确认的投资方法。先阅读[长篇框架](../../framework/long-form-investment-framework.md)与[ontology](../../investment-ontology.md)，按用户已明确的含义开展工作。未确定的方法与取舍保留探索状态；冲突记录为张力，不以模板默认值替用户决定。

## 输入与准备

读取 AGENTS.md、`framework/valuation.md`、公司 thesis、valuation 和证据索引。输入是证券身份、可核实财务数据及价格、估值日期和研究目标。价格、持有期限或用户回报要求缺失时，不自行猜测；先完成不依赖它们的模型部分。

## 步骤

1. 解释选择的方法、必要性和更简单的替代方法；优先一种能清楚复算的方法，避免堆叠模型。
2. 登记输入证据，固定币种、单位、报告期、价格日期与股份口径；明确企业价值到股权价值的桥接。
3. 区分事实与预测，按研究问题建立必要情景（悲观、基准、乐观只是可用形式，不是用户已确认的固定方法），说明增长、盈利、资本投入、股数、净债务及退出假设的依据。
4. 计算每股价值，检查现金、债务、分红、回购和稀释是否重复计入或遗漏；展示公式和中间值。
5. 实际需要回报计算时明确现金流时点、期限、费用和税的处理。没有中间现金流时可以用年化回报；其他情况使用适用的 IRR 方法并检查无解、多解及数值收敛。
6. 简单计算直接写入 valuation；仅在复算确实需要时加入小型 Python 工具，并用独立已知结果与边界情况验证。
7. 展示最关键变量的敏感性、价格隐含预期、模型失效条件。参数变化追加更新记录。

## 输出与检查

输出情景区间、输入依据、计算过程、最敏感假设与缺口。未计算的部分明确标注；不能把助手设定的回报要求当作用户偏好。按 evals 检查假设是否与业务 thesis 一致；计算正确不代表假设成立。
