# 可重复执行的研究流程

Skill是Main使用的操作说明，不是自动软件或投资决定权。M022已落实第8个独立research-planning，M023进一步强化[立项与主动问题生成](../framework/initiation-and-question-generation.md)；不新增第9个Skill或常驻Question Agent，最终AGENTS仍暂缓。

先读临时[AGENTS](../AGENTS.md)、[长篇框架](../framework/long-form-investment-framework.md)、[ontology](../investment-ontology.md)及[Source & Evidence Policy](../framework/source-and-evidence-policy.md)。本轮方法来自M022直接要求，未明确的投资取舍不以模板默认替代；valuation仍保留通用草稿地位。整理理念/真实案例时先用材料流程/casebook，不把所有输入强行记为公司证据。

| Skill | 何时调用 | 主要结果 |
| --- | --- | --- |
| [candidate-screen](candidate-screen/SKILL.md) | Idea/立项 | 五份真实案例提炼的逻辑覆盖、business/FCF理解、价格风险与研究去留，非格式模仿 |
| [research-planning](research-planning/SKILL.md) | 未给具体问题时、立项后及研究/跟踪反复 | Business understanding → value-driver map →主动问题→三轴排序→Evidence/Source Plan；循环更新及线下brief |
| [deep-dive](deep-dive/SKILL.md) | 初步/深入研究 | 检验经营机制及替代解释，减少决策相关不确定性 |
| [evidence-update](evidence-update/SKILL.md) | 主动找资料或收到新材料 | claim-level评估、来源依赖、证据综合与受影响判断 |
| [thesis-management](thesis-management/SKILL.md) | 初步判断/实质变更/复盘 | 少数thesis、确认范围、formal/actionability分开及历史 |
| [earnings-update](earnings-update/SKILL.md) | 财报/经营披露 | thesis-driven监测、同口径变化及下一证据路径 |
| [valuation](valuation/SKILL.md) | 经营理解及输入足以支持计算 | 现金流、情景IRR、反向要求及敏感性 |
| [red-team](red-team/SKILL.md) | D4重要/高conviction情形默认，其他按需 | 先blind再adversarial的独立挑战方法 |

生命周期：Idea → 立项 → Planning → 初研 → Human Gate 1 → 深研 → Human Gate 2 → 持仓管理 → 跟踪。Planning可随时返回；evidence-update贯穿始终，不必每次从头重走。

Main在已确认问题/范围内主动选择公开来源、方法与工具；资料不足及时提出针对性的Jimmy一线任务，不默认等上传或盲目搜更多。临时研究者按有边界任务返回报告，不新增固定Source Agent；M023在历史能力回放中按用户允许调用临时独立生成者，只返回首次报告/问题；不是常驻Agent，也不按问题重合增加事实confidence。

确认针对material/decision-relevant change，不逐文件/小假设审批；实际持仓只据真实事实。新Skill及方法存在不表示行为评估已经通过。
